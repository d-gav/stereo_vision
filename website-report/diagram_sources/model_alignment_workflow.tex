  \node[draw=cornellred, line width=0.9pt, rounded corners=4pt, fill=paper,

       (note) at (70, -45)
       {\textbf{Why this alignment matters.} \,
        With shared parameter names and a single rectification LUT,
        \emph{nothing about the configuration can drift between the three
        paths}. When the RTL disparity map looks visibly wrong at a
        setting where Python's looks right, the bug has to be in the
        RTL --- \textcolor{cornellred}{not in a config mismatch.}};
